# 写作动机
本学期选修了宋磊老师的日本经济课程，非常精彩的一门通识课程。难能可贵的是，这门课并没有停留在简单的介绍层面，而是从逻辑角度展开的，可谓是“草蛇灰线，伏脉千里”。明天晚上要考试了，但是是开卷考试，所以也不怎么用背诵概念和细节，所以我就产生了一个大胆的想法：使用一篇文章，把整个学期的日本经济课程内容串联起来，争取体现出良好的因果逻辑关系，展现出不同事物之间的联系。

# 分析架构——主线
课程的研究主体是日本经济，因此宋老师很早就指出分析问题要从经济基础、根本性的角度进行分析，要尽量避免使用文化、特殊性等等方式进行解释。这是**宏观**上看待问题的角度。

而从更具体的知识角度来说，本学期的课程，归纳起来存在以下两个主线的问题，贯穿于整个学期的课程之中。

{: .highlight}
日本经济的宏观发展阶段

{: .highlight}
日本企业竞争力的来源以及变化

其中第一条主线是我们比较熟知的表象上的内容，而第二条主线是真正的在经济发展背后的核心驱动力。

为了更好地理解第二条主线，宋老师给出了以下几个分析问题的角度，是整个课程的核心内容。

{: .important}
日本经济为什么之前行，现在又不行了？从变化的角度看一整条时间线上的日本经济

{: .important}
理解后发优势与后发劣势，深入研究日本发展道路中的范式创新，着重关注与美国的对比

{: .important}
三大市场经济制度之间的互补性

{: .important}
企业组织形态与技术特征之间的互补性

{: .important}
政府在企业发展中的作用

# 知识串讲
## 从时间线看日本经济宏观表现
我们主要关注的是二战结束之后的日本经济发展，但是在战前有一个很重要的内容：**勤劳革命**。

{: .highlight}
>**勤劳革命**
>主要发生在农业领域，和工业革命的路径有所不同，勤劳革命是走向工业化的资本节约型与劳动密集型，通过大量增加劳动力来提高生产效率。日本后续的一切企业风格文化都大抵来源于此。

战后日本的经济发展宏观上可以分成下面几个时期：
- 战后重建期
- 高度成长期
- 稳定成长期
- 泡沫经济期
- 失去的十年
- 再次复兴
- 世界金融危机
- 愈发衰落的现在

这是一个由衰而盛，盛极必衰的完整的变化过程。但是在这个完整的变化过程中，日本内在的一些经济运行方式和经济制度本身是没有彻底变化的，**正是这些经济方式和制度使得日本能够在上世纪六七十年代迅速崛起，也正是它们使得日本在上世纪末开始的全球模块化浪潮中逐渐迷失，走向了衰落。**

整个系列课程的分析核心是高度成长期。

好的，现象已经摆出来了，下面就需要去分析原因了，在深入到日本具体的经济制度和产业实践之前，宋老师首先给出了一个非常深刻的、具有普适性的原因分析：**后发优势与后发劣势**

{: .highlight}
>**后发优势**
>
>作为赶超国家，可以参考借鉴世界领先国家的成功经验，避免试错，发展速度很快、发展成本相对低。
>
>**后发劣势**
>
>过快的挤压式发展，对成功国家的深层内容学习的不到位。

强调这两个概念，是因为中国目前所处的位置和当时的日本接近，因此我们有共通之处，无论是日本的成功经验还是失败教训都应该深入研究学习。而当下中国作为一个后发国家，也面临着要创新自己的发展范式的问题，这是我们摆脱后发国家的位置，成为真正的铺轨机司机的必经之路、关键一步。

所谓成败萧何，日本曾经在后发优势的加持下迅速发展，但是当后发优势随着日本经济水平提高逐渐消失后，以后发优势为基础的一些经济制度逐渐失灵，造成了日本后期经济发展的停滞。

而从微观的具体措施的角度概括，日本在高速发展期做的事情，主要就是**现代管理方法的全面引进和创造性改造**，相当于在抄作业的基础上走出了自己的风格：
- 从精英主义的品质管理到大众主义的质量管理
- 从品质管理到进一步的组织模式革新


## 日本经济的核心：企业主义
那么作为一个后进国家，主流经济学对其经济发展的概括可以分为两个角度：
- 国家的市场从不完善走向完善
- 企业构筑特殊能力，获得以技术为基础的垄断地位的过程。

这就引出了整个日本经济课最重要的两个对象：

{: .highlight}
市场和企业。

而日本经济的核心发展范式，就是**企业主义**。（之所以形成这个发展范式是一个非常复杂的问题，我们这里可以直接接受这个现象）日本企业在宏观经济中的地位，对国民的影响远远超过市场、国家、社会、地域、家族这些因素。**以企业为中心**将成为贯穿整个课程的分析方式。

在以企业为中心的架构下，日本企业本身坚持企业归从业人员所有的价值观，相对而言比较轻视股东，因此日本企业发展更关注市场份额而不是股价。

发展范式需要一系列制度进行引导、保驾护航，为了保持企业归从业人员所有这样朴素的价值观念，日本形成了两大妥协、三大法宝：

{: .highlight}
>两大妥协：
>
>- 劳资妥协：工资制度+雇佣制度
>- 金融妥协：主力银行与企业的关系；企业集团内部的关系
>
>劳资妥协与金融妥协是相互支撑的，这是一个完整的制度闭环。

{: .highlight}
>三大法宝（雇佣制度）：
>
>- 终身雇佣
>- 年功序列
>- 企业内工会

在这些基本制度的保障下，日本形成了信赖密集型的企业特点，企业间的合作、企业与银行的合作、企业内的雇佣，都保持长期、固定、封闭、信赖的关系。

这种内部环环相扣，自洽的体系与组织方式，是日本在高度成长期企业取得巨大发展的制度竞争力优势。但是这种方式带来的后果也很严重，产品过度的集成化，工种都是集成工种、工人掌握的都是企业特定的能力，工人与企业之间相互依赖严重，这本身就限制了企业应对变化的能力，为企业后期面对全球模块化生产的时候难以改革、创新能力不足埋下了伏笔。

## 三大市场制度

{: .warning}
前面写的还是很详细的，后面的话会更精简，更侧重于展现逻辑框架，减少细节的罗列。

在企业主义的基本思想下，日本的国内市场为了让企业主义能更好发展而形成适应企业建构的一套制度。

任何市场的建设过程中，都必须要解决信息不对称问题，保证市场的交易质量，下面来说说日本在企业主义的前提下是如何在不同市场中尝试解决信息不对称问题的。

### 金融市场
基本思路是通过长期反复交易逐渐建立信任关系和依赖关系，以此来解决信息不对称的问题。谁和谁长期反复交易？怎么保证双方可以长期交易？
- 企业和企业：企业之间交叉持股
- 企业和金融机构：主力银行与企业交叉持股；形成以主力银行为主体的企业治理机制
- 金融监管当局：低利率，降低企业融资成本；抑制债券市场，把资源引到银行

这种金融体系是以间接金融为主导的，其稳定的反面就是较低的资本流动率和效率，在高速增长期是可以坚持住的，同时也有利于促进长期、持续的工艺创新。但是当日本后发优势变小，工艺创新不再有足够的优势的时候，这种缺少风投的金融市场的问题就显现了出来，是造成日本后期企业创新的乏力。

### 劳动市场
在劳动市场中，也会出现劳动者实际工作量与评价方式之间不完全相符的信息不对称，俗话说就是“有人累成狗，有人磨洋工，最后拿的钱一样“，为了解决这个问题，日本企业的解决方式依然是长期主义：彻底长期的团队作业方式，人与人之间长期的合作建立信任和依赖，留出团队的协调空间。

除此之外，为了更进一步强化企业内部人与人之间，企业与劳动者之间的关系，日本企业内不细化分工，鼓励多能工，呈现出相对而言水平的信息流。

但是这套劳动制度在现代也出现了问题，由于个人承担的工作过分复杂，因此现代日本人普遍的工作压力、强度、时间都很大，造成了一定的问题。同时在现代生产方式下，以特定职位招聘的岗位型雇佣正在逐渐适应变化越来越激烈的市场环境，而日本的成员型雇佣逐渐失去竞争力。

### 制品市场
制品市场分成消费品市场和工业品市场。制品的质量是集中需要解决的信息不对称问题。和劳动市场、金融市场同理，日本在这方面也采用的是长期交易、反复交易、间接交易的方式，形成了消费品市场中复杂的流通环节以及工业品市场中的下请制度。

{: .warning}
总结来说，日本三大市场为了解决交易过程中的信息不对称问题，使用的都是长期、反复交易的方式。这种方式的坏处就在于调整交易对象的成本高、企业改革变化的成本高，而且天然在与海外企业进行交易的时候存在不适配的问题，难以参与到全球模块化生产之中。

{: .warning}
>- 金融市场主力银行制度+交叉持股 导致了过度贷款
>- 劳动市场终身雇佣+年功序列+企业内工会 导致了过量劳动
>- 制品市场企业集团下请制+固定交易 导致了工业品过量生产、消费品过度服务
>
>三个过度最终造成了过度竞争的局面。
>
>这些问题在经济规模快速扩张的时期被市场的扩张、经济发展抵消掉了，但是当日本失去后发优势，经济发展速度降低之后，这些问题就集中爆发了。

## 企业建设
阐述完企业所处的环境——市场之后，就要开始介绍企业具体的发展措施了，宋老师从四个不同的角度进行分析。

{: .highlight}
>- 企业战略
>- **企业的组织与技术建构**
>- 企业创新
>- 企业治理机制的变化

### 企业战略
所谓战略，听起来高屋建瓴，其实本质上就是**把握现状和理想状态的差距，然后使用客观的、可操作的、具体的方法来填补这个差距，并且在实践的过程中不断调整改进这个方法**。

一般来说，普遍认为企业对竞争优势来源有两点：**外部环境定位和内部竞争能力**。在日本的市场制度下，各大企业本身对自身定位的调整空间并不大，而注重市场份额的观念使得日本企业更加重视生产系统的改进，因此几乎所有日本企业都以生产的量、质的扩张为战略。

### 企业的组织与技术建构

{: .important}
这几乎是整个课程最重要、最精华的内容，极其本质深刻地指出了生产的产品“物”与生产者“人”的关系，以及从产品建构方式直击日本经济最近衰落的原因。

一个企业在战略引领下，为了打造自己的核心竞争力，必须要形成完善的**产品建构**和**组织建构**。一般来说这两种建构都可以分类为模块型和集成型。

日本企业的组织形态是集成型，因此为了匹配组织建构，传统日本企业普遍的产品建构也是集成型，这最终导致日本落入了集成化陷阱之中，在全球模块化生产的浪潮中失去了原先的领先地位。同时由于组织建构的集成化本身是源于企业主义这一最基本的理念，所以即使产品建构想要向模块化方向调整，依然会受限于难以作出调整的组织建构。

### 企业创新
如果说劳动市场和制品市场的特点限制了企业向模块化建构方向转型，那么金融市场的特点就限制了企业的创新（激进型创新）。

日本的科研水平其实是很高的，这从他们的诺贝尔奖获得者数量中可窥见一斑。但是如果深入分析获得科学诺贝尔奖的相关人士，可以发现日本科研重点相对而言更偏向于工程方面。

在日本企业战略、组织与技术建构的基础上，日本企业的创新呈现出：工序创新、渐进创新、封闭创新、基于技术的创新、集成型产业群的创新的特点，但这些本质上都还是集成化企业建构下的特点。

最近二三十年，无论是全球生产的模块化浪潮，还是以AI为代表的基于科学理论的创新成为业界主流，都决定了当今时代的主流创新范式是产品创新、激进创新、开放创新、基于科学的创新、模块型平台型产业的创新。日本，落后了。

{: .highlight}
那为啥日本搞不起来新式的创新？

这是因为新式创新（美国型创新）本质上是一个高风险的研发机制，重赏之下才能有勇夫，所以如果想要鼓励这种创新的话必须要有与之匹配的高回报机制。

但是我们回看前面的内容，就可以发现像日本这样间接金融为主、主力银行为主的金融市场体系，是无法提供美国式资本市场的超高的风投融资的。同时日本劳动市场的雇佣制度也决定了日本企业本身对新式创新的高风险的兜底接受能力还是很差的，员工不希望被裁员，企业也不希望失去培养出来的员工。

另外还有一点原因，就是日本搞产学合作的效果不太好，他们对产学结合进行规制，使得国立大学研究人员难以为民间企业服务，最有理论创新能力的一批人从制度上就已经和企业隔离开了。

### 企业治理机制的变化
在高速成长期结束之后，日本原先依赖的庞大制度系统已经显露出疲态和弊端，在外国资本进入的过程中，日本的企业治理机制也被动地出现了一些变化。

日本在高速成长期是以经济民主为哲学基础的，而经济民主通过提高劳动大众的地位、激发劳动群体的动力，有效地帮助日本发挥了后发优势，迅速实现了生产扩张。但是随着高速成长期结束，企业无法维持过往的高绩效，而且过度竞争的市场机制在此刻也开始显露疲态，所以传统的企业治理机制，在外资进入、主流意识形态变化的情况下出现了向美国型企业治理机制变化的倾向，从业员主导型逐渐被取代。但是由于日本企业本身又有较大的发展惯性，因而呈现出现如今的尴尬局面。

## 政府在企业发展中的作用
最后，宋老师和大家探讨了政企关系。这部分内容基本上讲日本政府如何嵌入前面所说的企业的建构的各个方面，帮助企业形成核心竞争力。

{: .highlight}
产业政策分为**产业结构政策**和**企业合理化政策**。
>- 产业结构政策：支持特定产业发展的政策（大刀阔斧）
>- 企业合理化政策：政府推动相关企业采用新技术、投资新设备，帮助企业提高管理水平和生产水平。（手术刀）

在日本的政策实践中，我们要找到其中既尊重了市场的规律，又有效发挥了政府作用的产业政策，而最终在分析了一系列案例之后，归纳出了以下的方式：

{: .important}
>- 改变产品建构
>- 推动企业以适应产品建构的方式发展组织形态、形成企业能力
>- 改变商业模式建构

这些只是总结性的经验之谈，他们有较高的成功率，但是在现在日本亟需大规模产业结构调整的时代，如何指定一个合理的产业政策，成为了一个艰巨的问题。

## 收束
以上就是对日本经济这门课程整个学期内容的高概括、高压缩的串讲。其实这门课的特点很鲜明，就是他没有使用完全意义上的分层式、模块化的讲述方式，
而是将各个部分紧密结合在了一起，用不同的主线把知识串联起来，因此上课的时候可能会略显混乱，但是把一整个学期的知识学完再回顾的时候，
颇有茅厕顿开、醍醐灌顶之感，并且已经不由自主地形成了一套分析问题的基本框架。我认为，这样的课程才是真正锻炼思维的、好的文科通识课程。
